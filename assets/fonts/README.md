# Zen Maru Gothic Bold

Source: https://github.com/google/fonts/tree/main/ofl/zenmarugothic
Original: ZenMaruGothic-Bold.ttf (Google Fonts official repository)
License: SIL Open Font License 1.1, see OFL.txt.

The complete original font was losslessly converted to WOFF2 using fontTools and Brotli 1.1.0 for smaller mobile downloads. Glyphs and font metadata have not been edited. The original TTF is not needed at runtime. The application serves the WOFF2 locally; Google Fonts APIs or accounts are not required. Build tools are not application dependencies.
