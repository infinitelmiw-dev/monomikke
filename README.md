# モノみっけ！ 投稿スタジオ

スマホで使える、APIキー不要・外部依存なしの投稿文章作成プロトタイプです。

## できること

- スマホ豆知識／スマホ便利グッズ／暮らしの便利グッズ／推し活グッズの4カテゴリー
- テーマと任意の紹介ポイントから、InstagramとThreadsの文章を同時に生成
- 文章の編集、コピー、自動保存、履歴の再編集・削除
- 下書き／投稿準備OK／投稿済みのステータス管理、履歴の絞り込み

生成はカテゴリー別テンプレートです。AI API、商品検索、事実確認、SNSへの自動投稿は行いません。特徴・価格・効果・対応機種などは投稿前に確認してください。Threadsは初期生成時500文字以内。編集で超過すると文字数を赤く表示します。

## Androidスマホだけで公開・利用する（おすすめ）

GitHub Pagesで無料のHTTPSサイトとして利用できます。PC・APIキー・パッケージインストールは不要です。

**[Androidだけで公開する手順](docs/ANDROID-PUBLISH.md)** を上から順に進めてください。GitHub Pagesの設定は `Deploy from a branch` → `main` → `/ (root)` です。公開するファイルは `index.html`、`style.css`、`generator.js`、`app.js` と任意の `.nojekyll`。すべて同じ階層に置きます。相対パスのため `/monomikke/` のようなサブパスでも動作します。

Pull Requestを使えば、スマホでマージしてPagesを有効にするだけで公開できます。ZIPのダウンロードやファイルの手動アップロードは不要です。実際の公開完了は、マージとPagesの設定後に確認してください。履歴は利用者のブラウザ内に保存され、旧URLから新URLには自動移行されません。

開発環境でスマホ用の配布ZIPを作り直す場合：

```sh
python3 scripts/package-pages.py
```

チェックアウトの隣に `monomikke-pages.zip` を生成します。ZIPを解凍して中のファイルをGitHubにアップロードしてください。

## PCでローカル起動（開発用）

Python 3があるPCで、このフォルダーを開いて実行：

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

PCのブラウザで `http://localhost:3000` を開きます。Node.jsもある場合は `npm start` でも同じサーバーを起動できます。依存パッケージのインストールは不要です。

## スマホで確認

1. このフォルダーのファイルをPCに用意し、上のサーバーを起動します。
2. PCとスマホを同じWi-Fiにつなぎます。
3. PCの設定でローカルIPv4アドレスを調べます（Windows: `ipconfig`、Mac: システム設定 → Wi-Fi → 詳細 → TCP/IP）。
4. スマホのSafariまたはChromeで `http://PCのIPv4アドレス:3000` を開きます。例： `http://192.168.1.20:3000`。スマホ側のlocalhostはPCには接続しません。
5. 接続できなければPCのファイアウォールでプライベートネットワーク上のPython受信を許可し、ゲストWi-Fiの端末間通信制限も確認します。

クラウド内のlocalhostにはスマホから直接アクセスできません。この手順はPCにファイルを用意した場合です。常時アクセスする場合は静的サイトとしてHTTPS配信できますが、この作業では外部公開していません。

コピーはHTTPSまたはlocalhostでClipboard APIを使用します。LAN上のHTTPなどで利用できない場合は従来のコピーを試し、失敗したら文章を選択して手動コピーを案内します。

履歴は同じブラウザ・同じURLのlocalStorageに保存します。別端末や別URLとの同期・バックアップはありません。プライベートブラウズやデータ削除では消失する場合があります。保存できない場合は画面に通知します。

## 検証

```sh
npm test
```

Node.js標準のテストランナーで全カテゴリーの生成、入力検証、Threadsの文字数上限を検証します。
